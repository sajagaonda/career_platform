설치 순서
① 세 구글폼에 공통 질문 참가자 번호(01~33)를 필수로 만드세요. 번호가 같아야 같은 참가자로 집계됩니다.
② 각 구글폼 응답을 연결한 구글시트에서, 참가자 번호 / 이름 / 대표 이미지 URL / 결과물 URL / 타임스탬프만 포함하는 공개 전용 시트 탭을 만드세요. 이메일·전화번호·상세 인터뷰 등 개인정보는 넣지 마세요.
③ 각 공개용 시트 탭을 파일 → 공유 → 웹에 게시 → 해당 시트 선택 → CSV로 게시합니다.
④ 이 HTML 파일 아래쪽 CONFIG.sheets의 주소 3개(선택적으로 명단 주소 1개)를 채운 뒤 GitHub Pages에 올리세요.
⑤ 명단 시트가 없다면 HTML의 PARTICIPANT_NAMES 배열에 33명의 이름을 순서대로 입력할 수 있습니다.
⑥ 응답이 들어오면 주기적으로 자동 반영됩니다. 구글시트 게시 데이터 반영에는 수 분이 걸릴 수 있습니다.
이미지 : 공개적으로 열람 가능한 이미지 URL을 넣으면 카드 배경으로 나타납니다. 구글폼 파일 업로드를 사용한다면 구글 로그인과 이미지 파일의 공개 권한이 필요하며, CSV에 파일 이름만 나오고 링크 URL이 빠지는 경우에는 URL 열을 별도로 마련해야 합니다.
주의 : 시트의 웹 게시 데이터는 공개될 수 있습니다. 참가자의 공개 동의를 받고, 원본 응답 탭이 아닌 공개용 탭만 게시하세요. 연결 오류 시 제출 여부를 미확인으로 표시합니다.
